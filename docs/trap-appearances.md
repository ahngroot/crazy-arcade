# 갇힘 외형 6종과 HELP!

기존 character-motion.png / trapped-alternate.png의 2종을 보존하고, 사용자 첨부 스크린샷 4장을 참고한 trapped-extra.png의 4종을 추가했다. 신규 시트는 4열2행이며 위는 일반, 아래는 같은 열의 흰 거품 모습이다. 배경·닉네임·HELP 글자를 분리해 새로 재구성한 그림이며 원본 픽셀 추출본/동일본은 아니다.

플레이어 ID와 갇힘 종료 시각의 해시를 unsigned로 바꿔 6으로 나눈 나머지로 외형을 고른다. 한 번 갇힌 동안은 고정하고 다음 갇힘에서 다시 선택한다. 반복 선택은 가능하며 게임 RNG나 판정 상태는 변경하지 않는다. 익사 직전에는 해당 외형의 흰 거품을 연결하고 이후 기존 엎드림/페이드/부활을 유지한다.

trapped-help.png는 사진의 노란 글자·주황 음영·짙은 테두리를 참고해 재구성했다. 갇힌 모든 캐릭터 위에 표시하고 이동을 따라간다. 익사·탈출 때 숨기며 플레이어 삭제·렌더러 초기화·종료 때 정리한다. 갇힘5초·0.8칸/초·아이템·바늘 판정은 변경하지 않는다.

검증: 타입 검사·제품 빌드·Vitest138개 통과. 관련 Chromium4개에서 6종 모두 출현/선택 고정/서버 상태 비변경/HELP 표시와 숨김/각 흰 거품/엎드림/부활/종료 정리를 확인했다. 전체 브라우저 재실행 결과는 아니다. Windows ZIP 생성·CRC·SHA-256 확인 완료이며 Windows 네이티브 실행은 별도 검증이다.
