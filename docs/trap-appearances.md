# 갇힘 외형 4종과 HELP!

최신 부유 연출: 네 외형 모두 갇힘/익사 직전 그림이 약1.76초 주기로 위쪽0~4px에서 둥둥 움직인다. 흰 거품도 같은 위치를 따른다. 실제 좌표·바닥 그림자·HELP·자기 화살표·이동/갇힘 판정은 유지한다. 타입 검사·빌드·Vitest138개·관련 Chromium3개 통과. 위치 범위와 거품 일치·상태 비변경·사망/부활을 확인했다. ZIP CRC·SHA-256 확인 완료이며 Windows 실기기 검증은 별도다.

사용자가 표시된 삭제 대상을 확인해 trapped-extra.png의 왼쪽2/4번째 외형과 해당 흰 거품의 텍스처 등록 및 무작위 선택을 제거했다. 원본 시트는 나머지 외형의 소스로 보존한다. 기존2종과 왼쪽1/3번째 외형만 사용한다.

플레이어 ID와 갇힘 종료 시각의 해시를 unsigned로 바꿔 4로 나눈 나머지로 고른다. 한 번 갇힌 동안 고정하며 반복 선택은 가능하다. 게임 RNG나 판정 상태는 변경하지 않는다. 각 외형의 흰 거품·HELP!·익사·엎드림·부활을 유지한다. 그림은 첨부 사진 기반 재구성이며 원본 픽셀 동일본은 아니다.

검증: 타입 검사·빌드·Vitest138개 통과. 관련 Chromium1개에서 네 외형 모두 선택/유지/각 흰 거품/HELP 표시와 숨김/익사/부활/정리를 확인했다. 전체 브라우저 재실행 결과는 아니다. Windows ZIP CRC·SHA-256 확인 완료이며 Windows 실기기 실행은 별도다.
