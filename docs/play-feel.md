# 화면 크기와 타일 이동, 사망 드롭 연출

캐릭터는 테마 맵에서 상하좌우 한 칸씩 연속 이동한다. 키를 짧게 눌러도 현재 이동 중인 칸의 중심까지 도달한 뒤 정지하고, 다른 방향을 누르면 다음 중심에서 방향을 바꾼다. 보간된 연속 이동이며 화면에서 순간이동하지 않는다. 서버와 클라이언트 예측이 같은 moveTarget 판정을 사용한다. 갇힌 상태는 기본 속도의 40%를 유지하며 사망·재생성 때 이동 목표를 지운다. 과거 레거시 fixture의 자유 이동은 제품에서 사용하지 않는다.

캐릭터 그림의 알파 영역을 측정해 투명 여백을 제거하고 비율을 유지해 캔버스를 채운다. 발 위치와 타일 중심은 유지하며 머리 부분은 위로 올라온다. 바닥 아이템은 기존 27×28.5에서 40.5×42.75로 가로/세로 1.5배 확대했다.

사망 드롭의 서버 상태에는 사망 위치, 시작 시각, 각 아이템의 착지 시각이 들어간다. 700ms부터 아이템마다 45ms 차이를 두고 착지하며 렌더러가 출발점→착지 타일의 포물선·회전·그림자를 그린다. 재접속해도 경기 시각에 맞는 위치를 그린다. 비행 중 픽업은 불가하며 기존 재생성/픽업 지연 규칙은 유지한다. 물줄기·울트라는 드롭하지 않는다.

경기 대화상자를 화면 너비의 99%로 확장하고 반복 안내/여백을 줄여 경기장을 확대했다. 맵 타일 수는 15×13으로 유지한다. 큰 화면은 경기장과 상태 패널을 나란히, 작은 화면은 상태 패널을 아래에 표시한다. 낮은 화면에서는 상태 패널을 별도로 스크롤하며 종료 버튼을 고정한다. 모바일 터치 조작 추가는 이번 변경에 포함하지 않는다.

검증: 타입 검사·빌드·Vitest 124개·전체 Chromium 33개 통과. scatter.spec.ts가 실제 렌더러에서 출발/비행/착지 좌표와 크기·포물선 높이를 검사하고 scatter-flight.png/scatter-landed.png를 캡처한다. 데스크톱 1440×1000에서 온라인 경기장 높이는 기존 약 580px에서 약 720px로 커졌으며 하단 버튼과 겹치지 않는다. 작은 화면의 가로 넘침·종료 접근과 연습/온라인 흐름도 확인했다.
