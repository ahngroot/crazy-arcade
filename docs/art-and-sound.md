# 5단계: 클로버 정원의 그래픽과 사운드

일반 대결형 연습 맵에는 직접 그린 체크 바닥, 파란 고정 기둥, 세 가지 색상의 파괴 블록을 추가했다. `terrain: battle`을 보고 전용 텍스처를 표시한다. 시작 안내는 경기장 중앙 DOM 오버레이로 3→2→1→Game Start!를 표시하며 reduced-motion 설정에서는 확대 애니메이션을 끈다.

## 오리지널 리소스

화면의 캐릭터·몬스터·지형·아이템·초상화·효과와 음악은 이 프로젝트에서 직접 작성했다. 원작 스프라이트·음원·로고를 추출하거나 외부 폰트/에셋 파일을 내려받지 않는다. 영감은 밝은 클래식 캐주얼 아케이드 감성이며, 원작 그래픽을 복제한 리소스가 아니다.

- **루비 / 모모:** 빨강·민트색 새싹 후드, 큰 머리와 작은 멜빵 몸통, 부츠·스카프, 얼굴 방향으로 구분한다. 4방향×4프레임 걷기/대기, 갇힘·탈락·승리·패배 표정을 원본 벡터 함수에서 생성한다. 대기 중 눈 깜박임, 걷기 팔다리와 몸통 변화, 갇힘의 놀란 표정·땀방울, 탈락의 사라짐, 재생성의 빛과 확대를 지원한다.
- **몬스터:** 초록 새싹 꼬물이, 보라 가시 까칠이형, 금빛 왕관 황금 몬스터를 각각 4프레임으로 그린다. 추격은 더 빠른 모션, 황금은 광채·별 입자·등장 문구를 사용한다.
- **맵:** 따뜻한 빨강 진영/민트색 초록 진영 바닥, 잎사귀 울타리, 나뭇결과 새싹 문양 상자, 발밑 그림자를 사용한다. 발 위치와 블록 하단을 기준으로 깊이를 정해 블록 뒤에 선 캐릭터가 자연스럽게 가려진다.
- **물풍선과 물줄기:** 입체 음영·반사광·대기 바운스, 폭발 중심의 밝은 원과 연결된 물줄기·끝부분을 구분한다. 반투명한 40×40 타일 바탕이 실제 피격 영역이고, 바깥으로 튀는 물방울은 피해 없는 장식이다. 상자가 부서지면 파편, 몬스터 처치에는 별, 재생성에는 빛 고리, 점수/콤보에는 짧은 숫자 팝업을 사용한다.
- **HUD:** 상태별 초상화, 숫자 점수·시간, 아이템 그림과 잔여 개수, 효과 남은 시간, 마지막 30/15초 경고, 트로피와 승패 표정을 표시한다. 소리·음량은 메뉴와 경기 화면에서 같은 설정을 공유한다.

`art.ts`의 Canvas 2D 벡터를 2배 해상도 텍스처로 만든 뒤 Phaser 캐시에 재사용한다. UI 초상화/아이콘은 인라인 SVG다. 외부 이미지 요청이 없으므로 원격 이미지 로딩 실패에 의존하지 않는다. 캐시에서 그림이 누락되면 직접 그린 대체 캐릭터 텍스처로 표시하며 이를 브라우저 테스트로 확인한다. Canvas/WebGL 자체를 지원하지 않는 브라우저까지 지원하는 것은 아니다.

## 게임 판정과 연출의 분리

`renderer.ts`는 받은 논리 상태를 읽고 화면 오브젝트만 관리한다. 지형은 변경된 경우만 갱신하며 스프라이트는 재사용한다. 파티클은 최대 220개, 원형 효과 32개, 떠오르는 문구 8개로 제한하고 세션 종료/재시작에 정리한다. 이 단계는 공통 게임 규칙이나 온라인 서버 판정을 변경하지 않는다.

`presentation.ts`는 객체 ID·플레이어 상태·능력치 등의 이전 값 사본을 보관해 확정된 상태 변화만 연출 이벤트로 만든다. 같은 온라인 스냅샷을 반복 받아도 효과음이나 폭발이 중복 재생되지 않는다. 초기 입장·재접속·라운드 재시작은 새 기준 상태로 처리해 지난 효과음이 한꺼번에 울리지 않는다. 드물게 한 스냅샷 사이에 발생하고 사라진 사건은 표현이 생략될 수 있으며, 연출 누락이 판정에 영향을 주지는 않는다.

경기장과 우측 정보 패널을 우선 배치하며 짧은 화면에서는 게임 영역 크기를 줄이고 종료 버튼을 유지한다. 좁은 화면은 패널을 아래로 배치하고 가로 넘침 없이 스크롤할 수 있다. 터치 조작은 아직 없으며 데스크톱 키보드 플레이가 기준이다. 경고/승리의 CSS 애니메이션은 `prefers-reduced-motion`을 따른다.

## 오리지널 사운드

**처음에는 소리가 꺼져 있다.** 메뉴나 경기 화면에서 **소리 켜기**를 누른다. 오디오 자동재생이 제한되면 클릭/키 입력을 기다리며, 소리가 지원되지 않아도 게임은 계속 플레이할 수 있다. 음량 0~100%와 켜짐 상태는 로컬 브라우저 설정에 보관한다. 설정 저장이 제한된 브라우저에서는 현재 페이지 안에서만 유지된다.

- 배경음악: D장조 / B단조 화성을 사용하는 112BPM의 4마디 루프, 32개 8분음표. 직접 작성한 멜로디·베이스·화음을 sine/triangle 발진기로 합성한다. 약 8.57초마다 반복하며 캐릭터 소리를 가리지 않게 낮은 음량으로 배치한다.
- 효과음 11종: 물풍선 설치, 폭발, 몬스터 처치, 콤보, 황금 등장, 획득/강화, 갇힘, 탈락, 재생성, 경기 결과, 시간 경고.
- 폭발의 물소리는 직접 생성한 시드 난수 잡음을 필터링하고 내려가는 음정과 섞는다. 음원 파일이나 녹음을 복사하지 않는다.
- 음악은 경기에서만 재생하고 결과 화면에는 짧은 팡파르를 사용한다. 메뉴 복귀·음소거·탭 숨김에는 예약 음악과 음원을 중지한다. 복귀 시 지난 음악을 몰아서 재생하지 않는다. 활성 음원은 최대 24개, 같은 효과음은 짧은 시간 중복 재생을 제한한다. 끝난 노드는 연결을 해제한다.

실제 스피커 음량·음질은 브라우저와 장치에 따라 다르며, 자동 테스트만으로 주관적인 음악 품질이나 모든 장치의 출력을 보장하지 않는다.

## 검증과 샘플

루트에서 `npm run typecheck`, `npm test`, `npm run build`, `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`를 실행한다.

- 상태 관찰 테스트: 입장/재접속 기준 상태, 중복 폭발·효과 억제, 상자 파편/아이템 획득 구분, 콤보·황금·점수·결과·경고, 탈락·재생성·재시작, 같은 프레임의 아이템 사용/획득을 검증한다.
- 오디오 테스트: 사용자의 켜기 제스처, 실제 게임 이벤트의 재생, 음량·음소거·설정 유지, 오디오 미지원 대체를 확인한다. OfflineAudioContext로 효과음 11종과 배경음악 한 루프를 실제 PCM으로 렌더링해 유한한 값·비무음·개별 출력의 클리핑 여부를 검사한다.
- 시각 테스트: 전체 캐릭터 시트, 누락 텍스처 대체, 갇힘·황금·승패 표정, 파티클 상한과 렌더러의 게임 상태 불변성을 확인한다. 희귀 연출은 개발 전용 `showcase.ts`의 제어된 시각 fixture로 캡처하며, 실제 8콤보 플레이를 브라우저에서 달성했다고 주장하는 검사는 아니다.
- 온라인 대전의 실제 이동/피격/아이템/방 입장/재접속/동일 결과/재대결 회귀 검사를 유지한다.
