# 설치 물풍선 선택

기존 보라색 구체와 사용자가 업로드한 `물풍선 이미지.zip`의 원본14종, 총15종을 시작 전 그림 버튼으로 선택한다. 이름은 화면에서 생략하고 접근성 레이블에만 번호를 사용한다. 클릭·방향키 선택, 로컬 저장, 연습 재시작을 지원한다.

원본 PNG는 다시 그리거나 덮어쓰지 않고 `apps/client/src/assets/balloon-skins/01.png`~`14.png`로 보관한다. 업로드 ZIP의14.png~1.png를 역순으로 연결해 사용자가 채팅에 보여준 순서대로 나열했다. `sources.json`에 원본 파일명과 SHA-256을 기록했으며14개 모두 ZIP 내용과 바이트가 동일함을 확인했다.

모든 사진은 불투명한 배경을 포함한다. 게임 표시에는 `balloon-cutout.ts`가 바깥에서 연결된 단색 배경의 알파만 가린다. 배경과 가장자리 색이 비슷한 검정/해골2종은 실루엣 마스크를 사용한다. 그림의 내부 색/무늬를 생성하거나 다시 그리지 않는다. 여백을 정리하고 비율을 유지해 공통 슬롯에 맞추므로 전체 스크린샷을 그대로 사각형으로 표시하는 것은 아니다. 원본 파일 자체와 런타임 마스크를 구분한다. 선택 미리보기와 게임 텍스처는 같은 마스크 결과를 사용한다.

온라인 방 생성/참가 시 서버가 정수ID0~14를 검증해 좌석과 플레이어에 보관한다. 재접속과 재대결에도 유지한다. 설치할 때 skinId를 물풍선에 복사하므로 이후 소유자의 상태와 무관하게 설치 당시의 외형을 유지한다. 오래된 플레이어/물풍선의 누락 값이나 로컬에 없는 외형은 ID0으로 표시한다.

일반/울트라 모두 선택한 설치 외형을 사용한다. 성능·설치/폭발 판정·표시 기본40.7×42.9px·맥동·상하 부유는 그대로다. 아이템의 개수+1 물풍선과 갇힘 외형 선택은 별도다.

여러 텍스처를 함께 그릴 때 일부 물풍선의 삼각형 영역에 바닥 텍스처가 잘못 표시되는 WebGL 현상을 확인했다. 설치 물풍선에만 BatchHandlerQuadSingle을 사용해 해결했다. 브라우저 검사는15종 실제 화면과 각 텍스처의 내부 RGB를 비교해 큰 영역이 사라지는 회귀를 검사한다. Canvas 렌더러의 기존 경로는 유지한다.

검증: 타입 검사·빌드·Vitest142개·전체 Chromium43개 통과. 선택/저장/재시작·두 온라인 플레이어의 서로 다른 선택·15종 설치 키와 표시 픽셀·상태 불변·기존 캐릭터/메뉴/좁은 화면/물풍선 연출과 나머지 연습/온라인/맵/갇힘/사망 흐름을 확인했다. ZIP CRC·SHA-256 확인 완료. Windows 실기기 실행 결과와 구분한다.
