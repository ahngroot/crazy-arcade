# 설치 물풍선 선택과 손질

최신 승인 크기: 우니(+10%) 기준 정지 실루엣 높이47.3733px로13종 정상 캐릭터를 맞춘다. 네 방향에 공통 높이를 적용하고 실제 좌우 최대 폭38px를 넘는 외형은 가로 배율을 별도로 제한한다(일부 외형은 비율 유지 미리보기보다 날씬하다). 발 경계는 position.y*40+4에 고정한다. 설치형 물풍선은 직전 크기에서5% 축소(본체 약33.35×35.15px). 아이템·갇힘46.2×57.75·충돌·기본속도4칸/초는 유지한다.


최신 변경: 인게임 설치 표시만 추가10% 축소했다. 선택 화면/이미지/본체 정렬은 유지하며 BALLOON_ART 표시 배율에0.9를 적용한다. 타입 검사·빌드·Vitest142개·관련 Chromium4개(선택/온라인/15종 픽셀·본체 통일/움직임) 통과. ZIP CRC·SHA-256 확인 완료. 아래12개 검증은 이전 손질 단계 기록이다.

기존+추가14종, 총15종을 시작 전 그림 버튼으로 선택한다. 화면에서 이름을 생략하고 접근성 레이블에만 번호를 쓴다. 클릭·방향키 선택, 로컬 저장, 연습 재시작, 온라인 좌석/재접속/재대결 보존을 지원한다. 설치 시 skinId를 복사하며 성능·물줄기·폭발 판정과 독립적이다.

사용자가 실제 테스트 후 거친 테두리/배경 잔여물, 스티커 같은 움직임, 다른 크기를 지적하고 원본에 가깝게 손질하도록 요청했다. 이 요청에 따라 이미지 도구로 원본 무늬와 색을 참고해 정리한 balloon-polished/a~d.png의 2×2 시트4장을 사용한다. 1~4/a,5~8/b,9~12/c,13·14·0/d 순서이며 마지막 빈 셀은 쓰지 않는다. 원본 PNG14장과 기존 placed-balloon.png는 그대로 보관한다. sources.json의 SHA-256은 보관된 원본에 해당하며 현재 표시용 손질 그림을 원본 픽셀 동일본으로 주장하지 않는다. 90%이상 유사도를 정량 검증한 결과도 아니다. 비교 화면에서 확인할 수 있다.

balloon-art.ts는 떨어진 배경 찌꺼기를 제거하고, 매듭/불꽃/돌고래 장식 대신 본체의 기준 영역을 맞춘다. 기준 캔버스144×160의 (72,96)에 본체를 두고, 분홍 물풍선의 중앙 폭94px를 기준으로 광학 보정한다. 현재15종 측정 중앙 폭은93~95px(분홍94px)이며 검사 허용치는±2px다. 게임에서 보이는 기본 본체 폭은 이전 크기에서10% 줄인 약35.1px다. 전체 텍스처 사각형은 장식을 포함하므로 약53.8×63.0px로 더 크며, 타일/충돌 크기는 바뀌지 않는다. 선택 이미지도 같은 정렬 결과를 사용한다.

설치 물풍선에는8개의 서로 다른 내부 수면 변형 프레임을90ms마다 적용한다. 변형은 작은 폭으로 제한해 무늬가 심하게 일그러지지 않게 하고, 전체 탄성 맥동·약5~7.5px 상하 부유·작은 흔들림·곡면을 따라 이동하는 반사광·거리별 그림자 수축을 함께 그린다. 폭발 직전 맥동은 빨라진다. 실제 위치/타이머/판정 상태는 변경하지 않는다. 개별 WebGL 배치로 일부 삼각형 영역이 잘리던 현상의 방지도 유지한다.

검증: 타입 검사·빌드·Vitest142개 통과. 관련 Chromium12개 통과(선택/온라인/15종 실제 화면 픽셀/본체 폭/8개 변형 프레임/맥동·부유/메뉴·좁은 화면6개 + 카운트다운/온라인 재접속·재대결/반복 실행/기존 렌더링6개). 전체43개를 다시 실행한 결과는 아니다. Windows ZIP CRC·SHA-256 확인 완료이며 네이티브 Windows 실행은 별도 검증이다.
