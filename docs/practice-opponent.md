# 1인 연습모드 해적 상대

로두마니는 시작 전 캐릭터 선택의14번째 항목(ID13)에서도 선택할 수 있다. 선택 버튼과 HUD는 입체 시트의 정면을 사용하고, 플레이어는 네 방향/걷기 외형을 공유한다. 사용자가 로두마니를 골라도 컴퓨터 상대는 별도 로두마니 한 명으로 유지한다. 사용자의 기본 속도는4칸/초이며 아이템/능력치/조작은 다른 캐릭터와 같다. 컴퓨터만2.5칸/초다. 브라우저 선택 저장·연습 재시작과 온라인 검증/재접속에도 ID13을 보존한다.

사용자가 제공한 앞·뒤·왼쪽·오른쪽 사진 네 장을 `apps/client/src/assets/practice-pirate/`에 원본 그대로 보관한다. `sources.json`에 각 PNG의 SHA-256을 기록한다.

사용자가 로두마니 외형의 입체감 보강 후 기존 캐릭터와 그림체/색감 통일을 요청하여, `characters.png`의 그림체를 참고해 이미지 도구로 편집한 `arcade.png`를 사용한다. 회색을 밝히고 피부색을 따뜻하게 하며 사실적인 천 질감·강한 광택 대신 픽셀 느낌과 단순한 음영으로 둥근 볼륨을 표현한다. 선택/HUD와 게임은 같은 새 시트를 사용한다. 이전 입체 시트 `volume.png`와 원본 네 장은 비교/복원용으로 보존한다. 2×2 시트 순서는 정면/뒤/왼쪽/오른쪽이다. 실제 3D 모델이나 실시간 광원은 아니며, 명암이 그려진 2D 스프라이트다. 원본 픽셀 동일본 또는95% 유사도 정량 검증을 주장하지 않는다.

`pirate-art.ts`는 시트 각 사분면에서 연결된 알파 영역만 남겨 미세한 잔여물을 제거하고, 현재 캐릭터들과 같은 우니 기준 약47.37px 높이·발 경계 `position.y*40+4`·최대 폭38px로 정렬한다. 생성된 스프라이트의 하체를 두 영역으로 나누어 기존16프레임/0.6초 걸음 주기를 적용한다. 정지하면 해당 방향의 정지 자세로 돌아간다.

`docs/previews/practice-pirate/walk.gif`는 실제 게임 렌더러에서 네 방향 정지/걷기를 2배 확대하여 촬영한 비교다. 위는 입체 정지 자세, 아래는 제자리 걷기 시연이다.

연습 시작/재시작 때 플레이어와 떨어진 안전한 바닥에 해적 한 명을 추가한다. 상대도 일반 획득 규칙으로 개수·물줄기·속도·울트라와 액티브 아이템을 먹는다. 기본2.5칸/초에서 속도 아이템을 먹으면0.5칸/초씩 강화되며 일반 상한6칸/초를 따른다. 사망 후 초기화는2.5칸/초이고 속도 드롭도 실제2.5 기준 강화 개수로 계산한다. 플레이어는 기존4칸/초를 유지한다.

AI는 열린 바닥 경로로 아이템을 찾아 이동한다. 상자 또는 플레이어가 물줄기 범위 안에 있고 설치 개수가 남으면, 가상 물풍선의 폭발·연쇄 시간을 예측하고 안전한 바닥으로 탈출 가능한 경우에만 설치한다. 설치 후에는 예상 물줄기 범위를 벗어난다. 막다른 곳에서 탈출할 수 없으면 설치하지 않는다. 바늘은 갇혔을 때, 쉴드는 위험한 위치에서 FIFO 순서에 맞춰 사용한다. 상대방이 경로를 막는 등 상황이 바뀌면 갇히거나 죽을 수 있는 기본 연습 AI다.

이동은 일반 충돌 검사를 사용한다. 속도 강화 후에도 정확한 지점에서 회전하도록 컴퓨터 전용 `practiceTarget`으로 마지막 고정 tick의 이동량을 제한한다. 사용자의 자유 직각 이동은 이 제한을 사용하지 않는다.

물줄기에 맞으면 기존 갇힘·사망·무작위 안전 부활 규칙을 따른다. 갇힘은 기존 공용 물풍선 외형을 사용하고 별도 엎드림 사진이 없어 사망 페이드는 입체 정면을 사용한다.

`stepPractice`의 입력 공급 함수를 통해 각 고정 tick에서 경로를 판단한다. 기존 배열 입력 경로도 유지한다. Chromium에서 네 방향 크기·실제 연습 시작/이동/재시작과 기존 맵/모서리 이동을 검증하며 Windows 실제 실행 확인은 별도다.
