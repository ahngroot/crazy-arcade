# 1인 연습모드 해적 상대

사용자가 제공한 앞·뒤·왼쪽·오른쪽 사진 네 장을 `apps/client/src/assets/practice-pirate/`에 원본 그대로 보관한다. `sources.json`에 각 PNG의 SHA-256을 기록한다. `pirate-art.ts`가 사진별 실루엣 경로로 배경을 제외하고 원본 픽셀을 그린다. 생성 이미지로 캐릭터를 다시 그리지 않는다. 표시 크기 조정에는 리샘플링이 들어가며 경계의 배경 제외는 수동 실루엣 기준이다.

현재 캐릭터들과 같은 우니 기준 약47.37px 높이·발 경계 `position.y*40+4`·최대 폭38px를 사용한다. 네 방향별 사진을 사용하며 왼쪽과 오른쪽도 각각 별도 원본이다. 별도 걷기 프레임이 없는 사진이므로 이동 중에는 해당 방향 원본 자세를 표시한다.

연습 시작/재시작 때 플레이어와 떨어진 안전한 바닥에 해적 한 명을 추가한다. 이동만 하며 물풍선·아이템을 사용하거나 바닥 아이템을 가져가지 않는다. 기본4칸/초, 직각 이동과 동일 충돌 검사를 사용한다. 현재 열린 바닥길을 돌아다니며 갈림길에서 경로를 고르고 막다른 곳에서 되돌아간다. 상자 너머로 길을 뚫거나 플레이어를 추격하는 전투 AI는 아니다.

물줄기에 맞으면 기존 갇힘·사망·무작위 안전 부활 규칙을 따른다. 갇힘은 기존 공용 물풍선 외형을 사용하고 별도 엎드림 사진이 없어 사망 페이드는 원본 정면을 사용한다. 온라인 플레이와 13종 캐릭터 선택에는 추가하지 않는다.

`stepPractice`의 입력 공급 함수를 통해 각 고정 tick에서 경로를 판단한다. 기존 배열 입력 경로도 유지한다. Chromium에서 네 방향 크기·실제 연습 시작/이동/재시작과 기존 맵/모서리 이동을 검증하며 Windows 실제 실행 확인은 별도다.
