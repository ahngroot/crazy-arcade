# 게임 규칙 및 구현 상태

현재 1인 연습 맵은 `createBattleMap()`의 일반 대결형 15×13 구조다. 중앙 분리벽이 없으며 고정 기둥과 부술 수 있는 색상 블록을 배치한다. 꼬물이 온라인 맵은 기존 분리 진영 구조를 유지한다. 두 모드 모두 중앙 3→2→1→Game Start! 후 시작하며 숫자를 표시하는 3초 동안 판정과 입력은 진행하지 않는다.

## 현재 아이템 조작 (2026-11-04 변경)

게임 이름은 **crazy myangcade / 크레이지 먕케이드**다. 바늘·보호막·파워를 합계 2개까지 보유하며 획득 순서대로 Ctrl 한 번당 하나씩 사용한다. 현재는 1인 연습과 온라인 1:1을 제공한다. 각자의 PC에서 방향키 이동·Space 물풍선·양쪽 Ctrl 아이템을 사용한다. 한 PC의 로컬 2인 플레이는 제거했고, 1인 연습은 캐릭터 한 명·시간제한 없음·시작 아이템 보호막→파워로 제공한다. 시작 아이템은 보호막→파워다. 앞의 아이템이 사용 불가능하면 순서를 유지한다. 가득 찼을 때 추가 사용 아이템은 바닥에 남고 물풍선 개수·거리·속도 강화는 즉시 적용한다.

## 출처와 불확실성

사용자 제공 계획은 크레이지아케이드 꼬물이 02를 참고한다. 이번 작업에서는 원작 영상이나 공식 규칙 원문을 독립적으로 검증하지 않았다. 따라서 원작과 일치한다고 확정할 수 있는 세부 수치는 없다.

계획에 기재된 참고 규칙: 빨강/초록 1:1, 처치 결과에 따른 상대 진영 몬스터 증가, 추격 몬스터, 콤보와 황금 몬스터. 합산 4마리 조건과 8연속 처치 조건은 원문 검증이 필요한 정보이며 확정 규칙으로 취급하지 않는다.

## 1단계 구현 (완료)

- 독자적인 시작 메뉴, 메뉴별 안내, Phaser 4.2.1 렌더링 테스트 장면.
- 대칭형 15×13 미리보기 맵, 정원 벽과 상자, 두 팀 캐릭터, 장식용 물풍선과 대기 애니메이션.
- 실제 Socket.IO 연결 상태 표시와 HTTP 건강 검사.
- 공통 타입 및 중앙 설정. 이후 단계의 게임 시뮬레이션과 방 관리에서도 사용한다.

아래 단계별 구현은 개발 이력이다. 2/3단계의 로컬 2인 메뉴는 제거했다. 1인 연습은 공통 엔진을 클라이언트에서 실행하며 온라인은 서버에서 실행한다.

## 2단계 구현 이력 (로컬 연습)

- `packages/shared/src/game.ts`가 브라우저 독립적인 게임 상태와 판정을 담당한다. 프레임 크기와 무관하게 60Hz 고정 스텝으로 진행한다. 로컬 모드는 클라이언트에서, 4단계 온라인 모드는 서버에서 실행한다.
- 두 플레이어는 동일한 초기 능력치, 좌우 독립 진영에서 시작한다. 대각선 정규화, 축별 벽 미끄러짐, 작은 코너 오차 보정, 시선/걷기 모션을 지원한다. 충돌은 타일 단위 위치와 몸체 반경 0.28칸을 사용한다.
- 물풍선은 격자 기준으로 설치된다. 초기 설치 칸을 겹치고 있던 플레이어만 빠져나갈 수 있으며, 몸체 전체가 떠나면 재진입을 막는다. 누른 채로 자동 반복 설치되지 않는다.
- 폭발은 중심 포함 십자형이다. 고정 벽 직전에서 중단, 상자까지 포함 후 중단, 다른 물풍선까지 도달하면 연쇄 후 중단한다. 같은 연쇄에서 지형은 동시에 평가하며 상자를 먼저 부쉈다고 그 뒤까지 관통하지 않는다. 물풍선 ID당 한 번만 폭발한다.
- 상자 파괴 후 45% 확률로 3종 중 하나의 아이템이 나온다. 새 아이템은 해당 물줄기가 끝난 뒤 획득 가능하다. 이미 놓인 아이템은 새로운 폭발에 소멸한다. 시드 기반 난수이며 초기 시드는 2701이다.
- 피격 시 1.5초 갇힘 → 0.8초 재생성 대기 → 안전한 진영 내 바닥에서 복귀한다. 안전한 칸이 없으면 대기한다. 재생성 후 1.5초 무적, 획득 능력치는 유지한다. 재생성 횟수는 점수가 아니다.
- 창 blur/탭 숨김/메뉴 종료 시 입력을 정리한다. 탭을 숨기면 게임 시간을 멈춘다. 활성 화면에서 프레임당 최대 250ms만 처리해 장시간 중단 후 입력이 한꺼번에 적용되지 않게 한다. Phaser의 시각적 delta 평활화는 사용하지 않는다.
- 위 내용은 몬스터 없는 일반 연습 모드다. 제한시간 대전은 다음 항목을 따른다.

## 3단계 구현 (로컬 꼬물이 대전)

`packages/shared/src/competition.ts`에서 몬스터 AI·생성/전달 대기열·처치·콤보·황금·접촉 탈락·점수·경기 종료를 관리한다. 180초 기본 경기와 30초 빠른 경기, 점수 비교 승패, 재대결을 지원한다. 물줄기 피격과 별도로 추격 몬스터 접촉은 즉시 탈락 후 재생성한다. 일반 몬스터 접촉은 안전하다. 특수 아이템은 바늘·보호막·일시 강화이며 양 팀의 초기 조건은 동일하다.

4마리 임계값의 계산 방식은 검증된 원작 공식이 아니라 현재 생존 일반+추격 개체 수에 따른 임시 해석이다. 자세한 계산, 안전 생성·상한·후반 빈도·점수·특수 아이템 수치와 조작법은 [competition.md](competition.md)에 기록한다. 모두 중앙 설정에서 변경 가능하다.

## 4단계 구현 (서버 권위형 온라인 대전)

2인 방 생성·8자리 코드/링크 공유·닉네임·READY·3초 카운트다운·결과·재대결·나가기를 구현했다. 서로 다른 방의 상태는 분리하며, 서버만 공통 게임 엔진을 실행해 점수와 경기 상태를 확정한다. 클라이언트는 이동/버튼과 시퀀스만 전송하며 자기 이동은 예측·승인 보정, 다른 캐릭터는 보간해 표시한다.

기존 로컬 경기 규칙을 재사용한다. 온라인 스케줄러 30Hz, 스냅샷 20Hz, 무입력 타임아웃 300ms, 재접속 유예 30초, 빈 방 정리 60초다. 일시적 연결 끊김에는 양측 경기를 멈추며, 유예 초과/나가기는 기권이다. 단순히 탭이 숨겨졌다고 온라인 시간이 멈추지는 않는다. 상세 상태·입력 검증·재접속 자격 증명과 테스트 범위는 [online.md](online.md)를 따른다. 서버가 외부에서 접근 가능할 때 별도 PC 접속이 가능한 구조이며, 공개 서비스 배포는 아직 하지 않았다.

## 임시 설계 수치

`packages/shared/src/index.ts`의 `GAME_CONFIG`가 단일 설정 원본이다.

| 항목                      | 초기값        | 상태                           |
| ------------------------- | ------------- | ------------------------------ |
| 맵 / 타일                 | 15×13 / 40px  | 미리보기 및 연습에서 사용      |
| 최대 인원                 | 2             | 온라인 방 인원 제한 적용       |
| 라운드                    | 180초         | 미검증 임시값                  |
| 이동                      | 초당 3칸      | 연습 적용, 원작 미검증         |
| 물풍선 대기 / 물줄기 지속 | 2.5초 / 0.5초 | 미검증 임시값                  |
| 기본 개수 / 거리          | 1개 / 1칸     | 미검증 임시값                  |
| 콤보 시간 / 황금 조건     | 3초 / 8회     | 대전 적용, 원작 세부 검증 필요 |
| 추격 몬스터 임계값        | 4             | 임시 해석 적용, 원작 미검증    |
| 시뮬레이션 / 스냅샷       | 30Hz / 20Hz   | 온라인 서버 적용               |
| 재접속 유예               | 30초          | 온라인 복구/기권 적용          |

연습에서 적용하는 물풍선 기본값도 원작 수치로 검증한 값은 아니다. 추가 설정: 물풍선/거리 최대 6, 이동속도 최대 초당 6칸, 속도 아이템 증가분 0.5칸/초, 코너 보정 최대 0.23칸. 모두 중앙 설정에서 조절한다.

## 5단계 구현 (오리지널 그래픽·사운드)

캐릭터의 4방향·대기·걷기·피격·승패 표정, 몬스터 4프레임, 그림자가 있는 지형/아이템, 십자 물줄기와 물방울·처치·상자 파편·재생성 효과를 오리지널 벡터 텍스처로 구성했다. 상태 초상화·아이템 슬롯과 결과 연출을 보강하고, 직접 합성한 음악·효과음과 사용자 소리/음량 조절을 추가했다. 공통 게임 규칙과 서버 판정은 변경하지 않았다. 표현과 검증 범위는 [art-and-sound.md](art-and-sound.md)를 참고한다.

## 6~8단계 상태

- 6단계: 플레이 QA·성능·비정상 입력·저FPS·지연 검증 완료. 재현과 측정 한계는 [qa.md](qa.md)를 따른다.
- 7단계: 사용자 요청에 따라 Docker·Render 공개 배포와 운영 검증 보류.
- 8단계: 로컬 기준 최종 점검·[원작 비교표](original-comparison.md)·[인수인계](handoff.md) 정리. 원작 조작감/수치 실측과 실제 Windows·인터넷·배포 환경 검증은 남아 있다.

메뉴 미리보기의 객체는 장식이며, 현재 실제 플레이는 1인 연습과 온라인 대전에서 실행한다. 원작 에셋·음원·로고를 사용하지 않는다.
