# 게임 규칙 및 구현 상태

최우선 최신 규칙: 갇힘 속도는 능력치와 무관하게 0.8칸/초다. 물줄기/울트라도 사망 드롭 대상이다. rangePickups는 실제 적용된 액체 개수를, ultraPickup은 획득한 울트라 효과 하나를 기록해 울트라 하나를 여러 액체로 복제하지 않는다. 대상 수가 3개 이하면 전부, 4개 이상이면 floor(N×0.8)개를 무작위 선택한다. 범위/개수/속도/보관함/버프 및 두 기록은 사망 때 모두 초기화한다. 빈 칸 무작위 부활·맵 전체 비행·착지 후15초 유지 규칙은 유지한다. 자기 캐릭터만 하늘색 화살표가 따라다니며 사망 중에는 숨긴다. 아래 과거 물줄기/울트라 제외 및 소량 드롭 버림 규칙보다 이 안내를 우선한다.

최신 사망/갇힘 규칙: 갇힌 속도는 기본20%(0.6칸/초, 이전 갇힘 속도의 절반)다. 남은 액티브+실제 개수/속도 강화분 중 floor(N×0.8)개를 무작위로 골라 맵 전체 바닥에 드롭한다. 가까운 칸/같은 도달 영역으로 제한하지 않는다. 물줄기/울트라는 제외하며 전체 능력치는 초기화한다. 부활은 아이템/물풍선/살아있는 플레이어/폭발/근접 몬스터가 없는 안전한 빈 타일 중 무작위로 고르고, 후보가 없으면 대기한다. 소수점은 버린다(7개→5개, 4개→3개, 1개→0개). 아래 과거 전체 드롭/고정 위치 복귀보다 이 규칙을 우선한다.

최신 변경: 바닥 아이템은 생성/사망 비행 착지 후 15초 유지하고 마지막 3초에 옅어진다. 방향 입력이 있으면 벽에 막혀도 그 방향을 바라보며 제자리에서 걷는다. 위치/충돌 판정과 갇힘/사망 시간은 유지한다. 13종 방향 그림은 [캐릭터 그림 안내](character-motion.md)를 따른다. 아래 시간 안내는 이전 버전의 기록이다.

최신 변경: 방향키를 겹쳐 누르면 새 방향으로 꺾고 보조 키를 떼면 기존 방향으로 돌아갑니다. 바닥 아이템은 6초 유지하며 마지막 1.5초에 옅어져 사라집니다(사망 드롭은 착지부터 계산). 갇힘 5초 판정은 유지하며 남은 초 표시는 제거했습니다.

최신 화면/조작 갱신: 사망 위치에서 아이템이 빈 타일까지 포물선으로 날아가 착지한다. 캐릭터 그림의 투명 여백을 줄이고, 바닥 아이템을 가로/세로 1.5배로 키웠다. 타일 중심을 따라 연속 이동하며 중심에서 정지/회전한다. 화면에 맞춰 경기장을 확대하고 작은 화면의 상태 패널은 아래로 배치한다. 자세한 범위는 [play-feel.md](play-feel.md)를 따른다.

최신 맵은 [maps.md](maps.md)를 따른다. 연습과 온라인 모두 테마 7종과 빈 타일의 시작 위치를 무작위로 정한다. 공유 맵에는 인위적인 좌우 진영 제한이 없고 몬스터·드롭·재생성도 실제 맵의 이동 가능 지역을 따른다. 직전 맵은 다음 시작/초기화/재대결에서 제외한다. 사망·재접속은 맵을 바꾸지 않는다. 아래 정원 분리/일반 맵 고정 시작 설명은 과거 기록이다.

캐릭터 이름은 사용자 지정에 따라 배찌·우니·슈퍼 케피·럭셔리 마리드·슈퍼 다오·슈·디지니·다오·에띠·모스·후우·마리드·케피 순으로 표시한다. 선택 ID·외형·스펙은 바꾸지 않는다.

최신 사망/재생성 규칙: 익사와 추격 몬스터 사망은 공통 defeatPlayer를 거친다. 남은 액티브 보관함(최대 2개), 현재 개수 강화량, 현재 속도 강화량에 해당하는 아이템을 주변 바닥에 무작위로 떨어뜨린다. 강화 상한을 넘어 소비한 픽업·이미 사용한 액티브·교체로 버린 아이템·일시 버프의 추가 수치는 중복 생성하지 않는다. 물줄기/울트라는 드롭하지 않고 초기화한다. 능력치·보관함·모든 아이템 버프를 초기화하고, 선택 외형·점수는 유지한다.

배치는 공유 시드 RNG를 사용해 가까운 빈 바닥을 우선하며 온라인에서는 자기 진영을 벗어나지 않는다. 공간이 부족하면 기존 바닥에 겹쳐 놓아 수량을 보존한다. 벽/상자에는 놓지 않는다. 떨어진 아이템은 보이며 사망 연출 시간+0.5초까지 획득/물줄기 소실을 유예한다. 실제 재생성이 늦어져도 부활 후 0.5초간 픽업을 차단해 첫 상태가 기본 스펙임을 보장한다. 이후에는 정상적으로 다시 획득할 수 있다.

최신 보관 규칙: 액티브는 1번/2번 칸에 최근 2개를 보관한다. [A,B]에서 C 획득 시 A는 버리고 B를 1번, C를 2번에 저장한다. 획득만으로 발동하지 않으며 Ctrl은 1번부터 사용한다. 패시브는 보관 칸과 교체에 영향을 주지 않는다. 이 규칙은 추가 아이템을 바닥에 남기던 과거 규칙을 대체한다.

최신 이미지 구분: 파란 얼굴 물풍선은 물풍선 개수 +1 아이템이다. Space로 설치하는 풍선은 일반/울트라 모두 보라색 투명 구체다. 설치 외형에 사용했던 ultra 플래그는 제거했으며, 울트라 패시브의 최대 물줄기 효과·상자당 출현 3.75%는 유지한다. 반짝임·상하 흔들림·맥동 가속은 화면에서만 처리하고 폭발 시간·범위·충돌 판정은 바꾸지 않는다.

최신 울트라 확률: 기존 상자당 45%×1/6=7.5%에서 45%×1/12=3.75%로 절반 감소했다. 전체 아이템 드롭 45%는 유지하고, 아이템이 나올 때 물풍선/물줄기/롤러/바늘/쉴드는 각 11/60, 울트라는 5/60의 가중 추첨을 사용한다. 제외 장비는 계속 나오지 않는다. 울트라 패시브의 최대 물줄기/지속 효과는 유지한다. 새 ultra 플래그는 설치 풍선의 보라색 외형에만 쓰고 추가 능력치는 주지 않는다.

캐릭터 선택: 메뉴의 13종 외형 중 하나를 선택한 후 모드를 시작한다. 캐릭터 이름은 사진의 외형을 구분하는 임시 이름이다. 모든 캐릭터의 초기 이동속도·풍선 개수·물줄기·아이템·충돌 반경·갇힘·재생성 규칙이 같다. 서버는 선택값을 0~12 정수로 검증하고 좌석에 저장해 재대결·재접속에 유지한다. 미지정 구형 클라이언트는 0번으로 시작한다. 연습 초기화도 외형을 유지한다.

바늘·쉴드 복구: 연습/온라인 공통 상자 드롭에 바늘·쉴드를 추가했다. 이전에는 몬스터 보상에만 있어 연습에서 얻을 수 없었다. 둘 다 획득 시 보관 칸에 저장하고 자동 사용하지 않는다. 합계 2칸 FIFO Ctrl 규칙, 바늘의 갇힘 탈출·쉴드의 4초 보호는 유지한다. 액체·롤러·울트라 패시브, 장갑·신발·고스트 보류도 유지한다.

## 테스트 중 아이템 규칙 (최신, 아래 6초 울트라 규칙을 대체)

액체·롤러스케이트·울트라 물풍선은 획득 즉시 적용되는 패시브다. 울트라는 `range`를 최대 6칸으로 올리고 만료되지 않으며, 가득 찬 보관 칸과 관계없이 획득한다. Ctrl 없이 적용되고 재시작·재대결에서 초기화된다. 장갑·신발·고스트는 연습/온라인 공통 상자 드롭과 제품 안내에서 제외했다. 추후 복구할 수 있도록 타입·그래픽·장비 구현은 보존한다. 기존 물풍선 개수 강화 및 바늘·보호막·파워 보상은 유지한다.

## 2026-11-09 최신 규칙 (아래 과거 지급 규칙을 대체)

연습·온라인·재대결 모두 사용 아이템 없이 시작한다. 물풍선에 갇히면 5초 동안 능력치와 관계없이 기본 이동속도×0.2로 이동한다. 설치·획득은 할 수 없고, 바늘 탈출은 유지한다. 남은 호흡 표시·가속하는 몸부림과 기포·합성 꾸륵 소리 후 사망한다. 0.6초 질식 연출, 물방울 파열, 쓰러짐과 1.2초 사라짐 후 기존 모드의 안전한 위치 재생성을 유지한다.

첨부 이미지의 종류·색상·실루엣을 참고해 직접 Canvas/SVG로 그렸다. 원본 이미지의 픽셀 복제는 아니다. 액체(파란 병)는 물줄기 +1, 롤러스케이트(바퀴 달린 부츠)는 속도 +0.5로 즉시 적용한다. 울트라(보라/노랑 물풍선)는 최대 물줄기, 장갑(빨간 글러브)은 물풍선 2칸 던지기, 신발(파랑/노랑)은 물풍선 1칸 밀기, 고스트(회색 유령)는 상대에게 캐릭터·그림자·버프 테두리를 숨긴다. 사용 아이템은 합계 2개·획득 순서대로 Ctrl로 활성화한다. 장갑/신발은 활성화 후 방향키로 물풍선에 접근하면 작동한다. 착지 지점은 빈 바닥이어야 하며 소유자와 폭발 시간은 유지된다. 물풍선 이동은 서버 판정만 수행하고 클라이언트 이동 예측에서는 수행하지 않는다.

지속시간 6초, 던지기 2칸, 최대 거리 6칸은 이미지에 수치가 없어 정한 임시값이다. 기존 바늘·보호막·파워 보상 및 물풍선 개수 강화는 유지한다. 고스트는 시각 효과이며 서버 상태를 숨기는 치트 방지 기능은 아니다.

현재 1인 연습 맵은 `createBattleMap()`의 일반 대결형 15×13 구조다. 중앙 분리벽이 없으며 고정 기둥과 부술 수 있는 색상 블록을 배치한다. 꼬물이 온라인 맵은 기존 분리 진영 구조를 유지한다. 두 모드 모두 중앙 3→2→1→Game Start! 후 시작하며 숫자를 표시하는 3초 동안 판정과 입력은 진행하지 않는다.

## 현재 아이템 조작 (2026-11-04 변경)

게임 이름은 **crazy myangcade / 크레이지 먕케이드**다. 바늘·보호막·파워를 합계 2개까지 보유하며 획득 순서대로 Ctrl 한 번당 하나씩 사용한다. 현재는 1인 연습과 온라인 1:1을 제공한다. 각자의 PC에서 방향키 이동·Space 물풍선·양쪽 Ctrl 아이템을 사용한다. 한 PC의 로컬 2인 플레이는 제거했고, 1인 연습은 캐릭터 한 명·시간제한 없음·시작 아이템 보호막→파워로 제공한다. 시작 아이템은 보호막→파워다. 앞의 아이템이 사용 불가능하면 순서를 유지한다. 가득 찼을 때 추가 사용 아이템은 바닥에 남고 물풍선 개수·거리·속도 강화는 즉시 적용한다.

## 출처와 불확실성

사용자 제공 계획은 크레이지아케이드 꼬물이 02를 참고한다. 이번 작업에서는 원작 영상이나 공식 규칙 원문을 독립적으로 검증하지 않았다. 따라서 원작과 일치한다고 확정할 수 있는 세부 수치는 없다.

계획에 기재된 참고 규칙: 빨강/초록 1:1, 처치 결과에 따른 상대 진영 몬스터 증가, 추격 몬스터, 콤보와 황금 몬스터. 합산 4마리 조건과 8연속 처치 조건은 원문 검증이 필요한 정보이며 확정 규칙으로 취급하지 않는다.

## 1단계 구현 (완료)

- 독자적인 시작 메뉴, 메뉴별 안내, Phaser 4.2.1 렌더링 테스트 장면.
- 대칭형 15×13 미리보기 맵, 정원 벽과 상자, 두 팀 캐릭터, 장식용 물풍선과 대기 애니메이션.
- 실제 Socket.IO 연결 상태 표시와 HTTP 건강 검사.
- 공통 타입 및 중앙 설정. 이후 단계의 게임 시뮬레이션과 방 관리에서도 사용한다.

아래 단계별 구현은 개발 이력이다. 2/3단계의 로컬 2인 메뉴는 제거했다. 1인 연습은 공통 엔진을 클라이언트에서 실행하며 온라인은 서버에서 실행한다.

## 2단계 구현 이력 (로컬 연습)

- `packages/shared/src/game.ts`가 브라우저 독립적인 게임 상태와 판정을 담당한다. 프레임 크기와 무관하게 60Hz 고정 스텝으로 진행한다. 로컬 모드는 클라이언트에서, 4단계 온라인 모드는 서버에서 실행한다.
- 두 플레이어는 동일한 초기 능력치, 좌우 독립 진영에서 시작한다. 대각선 정규화, 축별 벽 미끄러짐, 작은 코너 오차 보정, 시선/걷기 모션을 지원한다. 충돌은 타일 단위 위치와 몸체 반경 0.28칸을 사용한다.
- 물풍선은 격자 기준으로 설치된다. 초기 설치 칸을 겹치고 있던 플레이어만 빠져나갈 수 있으며, 몸체 전체가 떠나면 재진입을 막는다. 누른 채로 자동 반복 설치되지 않는다.
- 폭발은 중심 포함 십자형이다. 고정 벽 직전에서 중단, 상자까지 포함 후 중단, 다른 물풍선까지 도달하면 연쇄 후 중단한다. 같은 연쇄에서 지형은 동시에 평가하며 상자를 먼저 부쉈다고 그 뒤까지 관통하지 않는다. 물풍선 ID당 한 번만 폭발한다.
- 상자 파괴 후 45% 확률로 3종 중 하나의 아이템이 나온다. 새 아이템은 해당 물줄기가 끝난 뒤 획득 가능하다. 이미 놓인 아이템은 새로운 폭발에 소멸한다. 시드 기반 난수이며 초기 시드는 2701이다.
- 피격 시 1.5초 갇힘 → 0.8초 재생성 대기 → 안전한 진영 내 바닥에서 복귀한다. 안전한 칸이 없으면 대기한다. 재생성 후 1.5초 무적, 획득 능력치는 유지한다. 재생성 횟수는 점수가 아니다.
- 창 blur/탭 숨김/메뉴 종료 시 입력을 정리한다. 탭을 숨기면 게임 시간을 멈춘다. 활성 화면에서 프레임당 최대 250ms만 처리해 장시간 중단 후 입력이 한꺼번에 적용되지 않게 한다. Phaser의 시각적 delta 평활화는 사용하지 않는다.
- 위 내용은 몬스터 없는 일반 연습 모드다. 제한시간 대전은 다음 항목을 따른다.

## 3단계 구현 (로컬 꼬물이 대전)

`packages/shared/src/competition.ts`에서 몬스터 AI·생성/전달 대기열·처치·콤보·황금·접촉 탈락·점수·경기 종료를 관리한다. 180초 기본 경기와 30초 빠른 경기, 점수 비교 승패, 재대결을 지원한다. 물줄기 피격과 별도로 추격 몬스터 접촉은 즉시 탈락 후 재생성한다. 일반 몬스터 접촉은 안전하다. 특수 아이템은 바늘·보호막·일시 강화이며 양 팀의 초기 조건은 동일하다.

4마리 임계값의 계산 방식은 검증된 원작 공식이 아니라 현재 생존 일반+추격 개체 수에 따른 임시 해석이다. 자세한 계산, 안전 생성·상한·후반 빈도·점수·특수 아이템 수치와 조작법은 [competition.md](competition.md)에 기록한다. 모두 중앙 설정에서 변경 가능하다.

## 4단계 구현 (서버 권위형 온라인 대전)

2인 방 생성·8자리 코드/링크 공유·닉네임·READY·3초 카운트다운·결과·재대결·나가기를 구현했다. 서로 다른 방의 상태는 분리하며, 서버만 공통 게임 엔진을 실행해 점수와 경기 상태를 확정한다. 클라이언트는 이동/버튼과 시퀀스만 전송하며 자기 이동은 예측·승인 보정, 다른 캐릭터는 보간해 표시한다.

기존 로컬 경기 규칙을 재사용한다. 온라인 스케줄러 30Hz, 스냅샷 20Hz, 무입력 타임아웃 300ms, 재접속 유예 30초, 빈 방 정리 60초다. 일시적 연결 끊김에는 양측 경기를 멈추며, 유예 초과/나가기는 기권이다. 단순히 탭이 숨겨졌다고 온라인 시간이 멈추지는 않는다. 상세 상태·입력 검증·재접속 자격 증명과 테스트 범위는 [online.md](online.md)를 따른다. 서버가 외부에서 접근 가능할 때 별도 PC 접속이 가능한 구조이며, 공개 서비스 배포는 아직 하지 않았다.

## 임시 설계 수치

`packages/shared/src/index.ts`의 `GAME_CONFIG`가 단일 설정 원본이다.

| 항목                      | 초기값        | 상태                           |
| ------------------------- | ------------- | ------------------------------ |
| 맵 / 타일                 | 15×13 / 40px  | 미리보기 및 연습에서 사용      |
| 최대 인원                 | 2             | 온라인 방 인원 제한 적용       |
| 라운드                    | 180초         | 미검증 임시값                  |
| 이동                      | 초당 3칸      | 연습 적용, 원작 미검증         |
| 물풍선 대기 / 물줄기 지속 | 2.5초 / 0.5초 | 미검증 임시값                  |
| 기본 개수 / 거리          | 1개 / 1칸     | 미검증 임시값                  |
| 콤보 시간 / 황금 조건     | 3초 / 8회     | 대전 적용, 원작 세부 검증 필요 |

## 5단계 구현 (오리지널 그래픽·사운드)

캐릭터의 4방향·대기·걷기·피격·승패 표정, 몬스터 4프레임, 그림자가 있는 지형/아이템, 십자 물줄기와 물방울·처치·상자 파편·재생성 효과를 오리지널 벡터 텍스처로 구성했다. 상태 초상화·아이템 슬롯과 결과 연출을 보강하고, 직접 합성한 음악·효과음과 사용자 소리/음량 조절을 추가했다. 공통 게임 규칙과 서버 판정은 변경하지 않았다. 표현과 검증 범위는 [art-and-sound.md](art-and-sound.md)를 참고한다.

## 6~8단계 상태

- 6단계: 플레이 QA·성능·비정상 입력·저FPS·지연 검증 완료. 재현과 측정 한계는 [qa.md](qa.md)를 따른다.
- 7단계: 사용자 요청에 따라 Docker·Render 공개 배포와 운영 검증 보류.
- 8단계: 로컬 기준 최종 점검·[원작 비교표](original-comparison.md)·[인수인계](handoff.md) 정리. 원작 조작감/수치 실측과 실제 Windows·인터넷·배포 환경 검증은 남아 있다.

메뉴 미리보기의 객체는 장식이며, 현재 실제 플레이는 1인 연습과 온라인 대전에서 실행한다. 원작 에셋·음원·로고를 사용하지 않는다.
