# 게임 규칙 및 구현 상태

## 출처와 불확실성

사용자 제공 계획은 크레이지아케이드 꼬물이 02를 참고한다. 이번 작업에서는 원작 영상이나 공식 규칙 원문을 독립적으로 검증하지 않았다. 따라서 원작과 일치한다고 확정할 수 있는 세부 수치는 없다.

계획에 기재된 참고 규칙: 빨강/초록 1:1, 처치 결과에 따른 상대 진영 몬스터 증가, 추격 몬스터, 콤보와 황금 몬스터. 합산 4마리 조건과 8연속 처치 조건은 원문 검증이 필요한 정보이며 확정 규칙으로 취급하지 않는다.

## 1단계 구현 (완료)

- 독자적인 시작 메뉴, 메뉴별 안내, Phaser 4.2.1 렌더링 테스트 장면.
- 대칭형 15×13 미리보기 맵, 정원 벽과 상자, 두 팀 캐릭터, 장식용 물풍선과 대기 애니메이션.
- 실제 Socket.IO 연결 상태 표시와 HTTP 건강 검사.
- 공통 타입 및 중앙 설정. 아직 게임 시뮬레이션이나 방 관리에 적용된 것은 아니다.

## 2단계 구현 (로컬 연습)

- `packages/shared/src/game.ts`가 브라우저 독립적인 게임 상태와 판정을 담당한다. 프레임 크기와 무관하게 60Hz 고정 스텝으로 진행한다. 향후 서버가 이 모듈을 소유하도록 설계했으며 현재는 로컬 클라이언트에서 실행한다.
- 두 플레이어는 동일한 초기 능력치, 좌우 독립 진영에서 시작한다. 대각선 정규화, 축별 벽 미끄러짐, 작은 코너 오차 보정, 시선/걷기 모션을 지원한다. 충돌은 타일 단위 위치와 몸체 반경 0.28칸을 사용한다.
- 물풍선은 격자 기준으로 설치된다. 초기 설치 칸을 겹치고 있던 플레이어만 빠져나갈 수 있으며, 몸체 전체가 떠나면 재진입을 막는다. 누른 채로 자동 반복 설치되지 않는다.
- 폭발은 중심 포함 십자형이다. 고정 벽 직전에서 중단, 상자까지 포함 후 중단, 다른 물풍선까지 도달하면 연쇄 후 중단한다. 같은 연쇄에서 지형은 동시에 평가하며 상자를 먼저 부쉈다고 그 뒤까지 관통하지 않는다. 물풍선 ID당 한 번만 폭발한다.
- 상자 파괴 후 45% 확률로 3종 중 하나의 아이템이 나온다. 새 아이템은 해당 물줄기가 끝난 뒤 획득 가능하다. 이미 놓인 아이템은 새로운 폭발에 소멸한다. 시드 기반 난수이며 초기 시드는 2701이다.
- 피격 시 1.5초 갇힘 → 0.8초 재생성 대기 → 안전한 진영 내 바닥에서 복귀한다. 안전한 칸이 없으면 대기한다. 재생성 후 1.5초 무적, 획득 능력치는 유지한다. 재생성 횟수는 점수가 아니다.
- 창 blur/탭 숨김/메뉴 종료 시 입력을 정리한다. 탭을 숨기면 게임 시간을 멈춘다. 활성 화면에서 프레임당 최대 250ms만 처리해 장시간 중단 후 입력이 한꺼번에 적용되지 않게 한다. Phaser의 시각적 delta 평활화는 사용하지 않는다.
- 시간제한, 몬스터, 콤보, 승패, 까칠이 접촉 판정, 인터넷 2인 플레이는 아직 없다. 다음 단계에서 접촉 피격은 물줄기 갇힘과 별도로 추가한다.

## 임시 설계 수치

`packages/shared/src/index.ts`의 `GAME_CONFIG`가 단일 설정 원본이다.

| 항목                      | 초기값        | 상태                             |
| ------------------------- | ------------- | -------------------------------- |
| 맵 / 타일                 | 15×13 / 40px  | 미리보기 및 연습에서 사용        |
| 최대 인원                 | 2             | 입장 기능 미구현                 |
| 라운드                    | 180초         | 미검증 임시값                    |
| 이동                      | 초당 3칸      | 연습 적용, 원작 미검증           |
| 물풍선 대기 / 물줄기 지속 | 2.5초 / 0.5초 | 미검증 임시값                    |
| 기본 개수 / 거리          | 1개 / 1칸     | 미검증 임시값                    |
| 콤보 시간 / 황금 조건     | 3초 / 8회     | 원작 검증 및 구현 필요           |
| 추격 몬스터 임계값        | 4             | 계산 방식 결정 및 근거 기록 필요 |
| 시뮬레이션 / 스냅샷       | 30Hz / 20Hz   | 설계값                           |
| 재접속 유예               | 30초          | 설계값                           |

연습에서 적용하는 물풍선 기본값도 원작 수치로 검증한 값은 아니다. 추가 설정: 물풍선/거리 최대 6, 이동속도 최대 초당 6칸, 속도 아이템 증가분 0.5칸/초, 코너 보정 최대 0.23칸. 모두 중앙 설정에서 조절한다.

## 이후 단계

3. 몬스터·상대 진영 전달·콤보·황금·특수 아이템·라운드.
4. 서버 권위형 게임방·READY·동기화·재접속·재대결.
5. 그래픽·사운드 고도화.
6. 플레이 QA·성능·비정상 입력 검증.
7. Docker·Render 배포와 운영 검증.
8. 원작 비교·조작감·밸런스 개선.

메뉴 미리보기의 객체는 장식이며, 실제 플레이는 연습 모드에서 실행한다. 원작 에셋·음원·로고를 사용하지 않는다.
