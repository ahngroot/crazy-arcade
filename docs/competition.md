# 3단계: 로컬 꼬물이 경쟁 모드

## 플레이

메뉴의 **꼬물이 대전**으로 시작한다. 기본 180초, 빠른 확인용으로 30초도 선택할 수 있다. 이 버튼은 두 사람이 한 PC의 키보드를 공유하는 로컬 모드다. 별도 브라우저로 만나는 **온라인 대전**은 [online.md](online.md)를 참고한다. 일반 **연습 모드**는 몬스터·시간제한 없이 그대로 사용할 수 있다.

| 플레이어 | 이동   | 물풍선 설치 | 다음 아이템 사용 |
| -------- | ------ | ----------- | ---------------- |
| P1 빨강  | WASD   | Space       | 왼쪽 Ctrl        |
| P2 초록  | 방향키 | Enter       | 오른쪽 Ctrl      |

캐릭터가 있는 진영에서 초록 몬스터를 물줄기로 처치하면 내 점수가 오르고, 상대 진영에 일반 몬스터 한 마리가 생성 대기열에 들어간다. 보라 추격 몬스터는 직접 닿으면 즉시 탈락하며, 물줄기 피격은 기존처럼 갇힘 후 탈락한다. 어느 경우에도 안전한 곳에서 재생성하므로 한 번 죽었다고 경기가 끝나지 않는다.

시작 물풍선은 하나이므로 상자를 부숴 이동로와 아이템을 확보한다. 양 팀은 보호막→파워 순서로 2개의 사용 아이템을 보유하고 시작한다. 추가 보상은 추격/황금 몬스터에게서 얻는다. 획득 순서대로 Ctrl을 한 번 누를 때 하나를 사용하며 누르고 있는 동안 반복하지 않는다. 바늘은 갇혔을 때, 보호막/파워는 활동 중에 사용할 수 있다. 앞의 아이템이 사용 불가능하면 보관 순서를 유지한다. 메뉴 이동은 현재 경기를 버리고, 경기 다시 시작/재대결은 점수·시드·맵·아이템까지 초기화한다.

## 적용한 임시 규칙 (원작 수치로 확인한 것이 아님)

- 일반 1점, 까칠이형 3점, 황금 10점. 마지막 처치 후 3초 이내면 콤보가 이어지고 2번째 처치부터 매번 1점 보너스.
- 8, 16, 24…연속 처치마다 자기 진영에 황금 몬스터 한 마리를 대기시킨다. 황금도 처치/콤보 대상으로 계산되며 상대에게는 일반 몬스터 한 마리만 전달한다.
- ‘4마리 기준’ 해석: 현재 진영의 일반+추격 몬스터 수를 4로 나눈 몫만큼 추격 몬스터를 목표로 추가한다. 최대 3마리이며 현재/대기 중인 추격 몬스터를 함께 세어 중복 요청을 막는다. 개체 수가 줄어도 이미 나온 추격 몬스터는 자동 삭제하지 않는다. 황금은 이 계산에서 제외한다.
- 첫 몬스터는 각 2마리, 위치는 좌우 대칭. 7초마다 양측 일반 몬스터 추가 → 경기 60초 경과 후 4초마다 → 마지막 30초에 1.4초마다. 마지막 15초는 별도 경고. 30초 짧은 경기는 처음부터 후반 구간이다.
- 일반 이동 초당 0.85칸, 추격 1.35칸, 황금 1.1칸. 추격은 바닥 연결을 BFS로 탐색하고, 일반/황금은 시드 난수로 방향을 고른다. 벽·상자·중앙 경계·물풍선 칸을 피한다. 새로운 물풍선이 목표 칸을 막으면 이전 중심으로 돌아가며, 출발/도착 칸이 모두 막히면 길이 열릴 때까지 기다린다.
- 추격 몬스터는 플레이어가 접근 가능한 바닥 연결 구역에만 생성된다. 통로가 막힌 동안에는 요청을 보관하며, 상자가 파괴되어 길이 열리면 생성한다. 일시적으로 접근이 막힌 AI는 가장 가까운 도달 가능 지점을 선택한다. 몬스터끼리 이동 중에는 서로 통과할 수 있다.
- 생성은 바닥, 물풍선/물줄기 밖, 플레이어로부터 1.7칸 이상, 다른 몬스터와 겹치지 않는 위치를 사용한다. 생성 직후 0.6초는 물줄기 및 접촉 판정을 유예한다.
- 진영당 생존 상한 22마리, 대기 상한 32마리. 대기는 팀/종류별로 집계되어 최대 6개 레코드만 유지된다. 0.25초마다 안전 위치를 다시 찾고, 황금/추격 요청을 먼저 시도한다. 공간이 없으면 대기하고 대기 상한을 넘는 요청은 버린다.
- 까칠이형 처치 시 특수 아이템 1개. 황금은 기본 10점과 특수 아이템 1개이며, 황금 아이템 지급은 설정으로 끌 수 있다. 보상 위치에 이미 아이템이 있으면 새 아이템을 겹쳐 놓지 않는다.
- 바늘: 갇힘 해제와 0.9초 보호. 보호막: 4초간 물줄기·추격 접촉 면역. 파워: 6초간 속도 +1.5칸/초, 거리 +2칸, 설치 개수 +2개. 영구 능력치를 변경하지 않으며 효과 종료 후 원래 값으로 돌아온다. 임시 강화 중 설치한 물풍선의 거리는 설치 시점 값이 유지된다. 사용 아이템은 종류/중복과 관계없이 합계 2개까지 보유하며, 가득 차면 추가 아이템은 바닥에 남는다. 물풍선 개수·거리·이동속도 강화는 즉시 적용하며 보관 한도에 포함하지 않는다.
- 시간 종료 시 점수로 승리/무승부를 확정하고 시뮬레이션을 멈춘다. 재생성 횟수는 승패에 영향을 주지 않는다. 일시적으로 탭을 숨기면 로컬 경기 시간이 멈추며, 실제 시간 권위는 4단계 서버에서 다룬다.

모든 밸런스는 `packages/shared/src/index.ts`의 `GAME_CONFIG`에서 바꾼다. 원작 규칙 출처의 검증 상태는 `rules.md`를 따른다.

## 검증 범위

Vitest는 몬스터 처치/중복 방지, 상대 전달, 까칠이 임계값, 추격 경로, 안전 생성/상한/대기열, 접촉 탈락/재생성, 콤보/황금 보상, 특수 아이템, 마지막 30/15초 경고, 전체 180초 승패와 종료 후 불변성, 같은 시드 재현을 검사한다.

Playwright는 기본 180초 선택 및 모드 분리, 두 사람의 실제 키보드 입력과 특수 아이템, 30초 경기 전체 진행→결과→재대결, 좁은 화면의 메뉴 접근을 검사한다. 180초 경기는 로직 전체를 자동 실행했으며 실제 브라우저 경기 전체 검증은 30초 모드에서 수행한다. Windows Chrome/Edge, 서로 다른 PC 접속, 원작 조작감·밸런스 비교는 별도 검증 대상이다.
