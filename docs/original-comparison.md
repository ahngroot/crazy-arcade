# 원작 비교와 밸런스 설정

## 비교 근거와 판정

사용자가 제공한 제작 계획의 참고 규칙과 현재 구현을 비교한다. 원작 공식 규칙 원문·플레이 영상·실행 환경을 독립적으로 확인하지 않았으므로, 현재 **원작과 일치한다고 검증한 항목은 없다**. 자동 테스트 통과는 이 프로젝트 규칙의 동작을 확인한 결과이며 원작 정확도의 근거가 아니다.

평가 분류는 `검증된 원작과 일치`, `대체로 유사하나 조정 필요`, `실제 원작 규칙을 검증하지 못함`이다. 아래 표의 **미검증**은 세 번째 분류를 뜻한다. 앞의 두 분류는 비교 자료를 확보한 뒤에만 부여한다.

| 비교 항목             | 현재 구현                                                               | 평가   | 확인할 자료/차이                                       |
| --------------------- | ----------------------------------------------------------------------- | ------ | ------------------------------------------------------ |
| 진영·맵               | 빨강/초록, 대칭 15×13, 중앙 경계, 독립 진영                             | 미검증 | 꼬물이 02 실제 타일 배치·시작 위치                     |
| 이동·모서리           | 초당 3칸, 대각선 정규화, 몸체 0.28칸, 코너 보정 0.23칸                  | 미검증 | 같은 구간 이동시간·코너 입력·벽 미끄러짐               |
| 물풍선                | 기본 1개·거리 1칸, 2.5초 뒤 폭발, 누름당 한 번 설치                     | 미검증 | 원작 설치 반응·연속 설치·기본 능력치                   |
| 물줄기·연쇄           | 0.5초 지속, 벽 중단, 상자 파괴 후 중단, 다른 물풍선 연쇄                | 미검증 | 프레임별 폭발·상자·연쇄 순서                           |
| 피격·복귀             | 1.5초 갇힘→0.8초 대기→안전 복귀, 1.5초 무적                             | 미검증 | 원작 탈락/부활 규칙·보호 시간                          |
| 일반 몬스터·상대 전달 | 일반 접촉 안전, 물줄기 처치당 상대에게 일반 1마리 전달                  | 미검증 | 몬스터 종류별 전달 수·생성 지연                        |
| 까칠이 출현·추격      | 일반+추격 수÷4의 몫을 목표로 추가, 추격 최대 3, BFS 이동                | 미검증 | ‘4마리’ 조건의 정확한 집계·변환/추가 방식              |
| 후반 난이도           | 각 2마리 시작, 7초→4초→마지막 30초 1.4초 주기                           | 미검증 | 시간대별 실제 생성률·상한                              |
| 콤보·황금             | 3초 이내 연속 처치, 8회마다 자기 진영에 황금 생성 대기                  | 미검증 | 콤보 단절·황금 등장 위치·점수/보상                     |
| 특수 아이템           | 바늘·4초 보호막·6초 강화, 합계 2개, 보호막→파워 시작, Ctrl 획득 순 사용 | 미검증 | 사용자 지정 보관/조작 규칙, 원작 지급·소모·효과 미검증 |
| 점수·승패             | 일반 1/추격 3/황금 10점, 2콤보부터 +1, 180초 점수 비교                  | 미검증 | 실제 배점·기본 경기시간·무승부 처리                    |

## 조절 가능한 설정

원본은 [`packages/shared/src/index.ts`](../packages/shared/src/index.ts)의 `GAME_CONFIG`다. 공통 엔진을 온라인 서버와 규칙 테스트가 사용한다. 현재 값은 임시 기준값이며 이번 정리에서 변경하지 않았다.

| 항목             | 설정 키                                                                      | 현재 값                                   |
| ---------------- | ---------------------------------------------------------------------------- | ----------------------------------------- |
| 플레이어 이동    | `movementTilesPerSecond`, `maxSpeed`, `cornerAssist`                         | 3칸/초, 최대 6, 보정 0.23칸               |
| 폭발 대기/지속   | `balloonFuseMs`, `blastMs`                                                   | 2500ms / 500ms                            |
| 물풍선 개수      | `initialBalloons`, `maxBalloons`                                             | 1 / 6                                     |
| 물줄기 길이      | `initialRange`, `maxRange`                                                   | 1 / 6                                     |
| 몬스터 생성 주기 | `monsterEarlyIntervalMs`, `monsterMiddleIntervalMs`, `monsterLateIntervalMs` | 7000 / 4000 / 1400ms                      |
| 난이도 전환      | `monsterMiddleAtMs`, `rushWarningMs`, `finalWarningMs`                       | 60초 경과 / 종료 30초·15초 전             |
| 개체/대기열 상한 | `maxMonstersPerTeam`, `maxSpawnQueuePerTeam`                                 | 진영당 22 / 32                            |
| 몬스터 속도      | `monsterSpeed`, `chaserSpeed`, `goldenSpeed`                                 | 0.85 / 1.35 / 1.1칸/초                    |
| 까칠이 출현      | `chaserThreshold`, `maxChasersPerTeam`                                       | 4마리 기준 / 최대 3                       |
| 콤보·황금        | `comboWindowMs`, `goldenCombo`, `comboBonus`                                 | 3000ms / 8회 / 추가 1점                   |
| 배점             | `normalScore`, `chaserScore`, `goldenScore`                                  | 1 / 3 / 10                                |
| 바늘·보호막      | `needleProtectionMs`, `shieldMs`                                             | 900 / 4000ms                              |
| 강화             | `powerMs`, `powerSpeedBonus`, `powerRangeBonus`, `powerCapacityBonus`        | 6000ms, 속도 +1.5, 거리 +2, 개수 +2       |
| 경기시간         | `roundMs`                                                                    | 기본 180000ms, UI의 빠른 테스트는 30000ms |

까칠이 조건은 `competition.ts`의 `maintainChasers`, 특수 아이템 시작 수량과 경기 시간 선택지는 각각 엔진/메뉴에도 정의되어 있다. 설정 키 변경만으로 맵 크기·플레이어 수·임의 경기시간 선택지까지 자동 확장되지는 않는다. 그런 구조 변경에는 맵·UI·입력 검증도 함께 수정해야 한다.

## 다음 비교 절차

현재 사용 아이템 보관 한도는 `inventoryLimit: 2`다. 동일 종류 2개도 한도를 모두 사용한다. 물풍선 개수·거리·이동속도 강화는 즉시 적용하며 보관 칸을 사용하지 않는다. 이는 사용자 요청에 따른 규칙으로, 원작에서 검증한 조건이 아니다.

1. 원작 버전·모드·맵, 출처 URL/영상 구간과 관측 날짜를 기록한다.
2. 이동·설치·폭발·처치·생성·특수 아이템을 각각 같은 조건으로 3회 이상 측정한다. 원작 측정과 현재 게임 측정을 구분한다.
3. 입력 지연은 로컬 측정부터 기록하고, 실제 PC 두 대의 회선/브라우저 조건과 서버 위치를 따로 기록한다.
4. 근거를 확보한 설정을 한 항목씩 변경한 뒤 타입 검사·게임 테스트·빌드·관련 브라우저 검사를 실행한다. 원작 확인값과 독자 밸런스 선택을 구분해 표를 갱신한다.

현재 자동 검증의 범위는 [qa.md](qa.md), 실제 PC에서 확인할 항목은 [handoff.md](handoff.md)를 따른다.
