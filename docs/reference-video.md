# 필수 BnB 외형 참고 자료와 확인 상태

사용자가 이후 정면을 바탕으로 모든 캐릭터의 옆·뒤와 걷기를 먼저 만들고, 나중에 참고 사진을 확보하면 교체하는 방식을 명시적으로 허용했다. 현재는 13종 방향 걷기를 구현했으며, 영상/원작과 동일하다고 주장하지 않는다. [현재 적용 범위](character-motion.md)를 따른다.

사용자는 https://youtu.be/PXftnij0syM?si=y7ZDXg958S3qKMNW 영상을 반드시 직접 참고하여 캐릭터 옆모습과 동작, 앞으로의 외형을 비교해 달라고 요청했다. 임의로 그린 그림을 해당 영상과 동일하다고 표시하지 않는다.

## 현재 접근 상태

2026-11-09 현재 지정 youtu.be 링크는 클라우드 egress 프록시에서 CONNECT 403 Forbidden으로 차단됐다. www.youtube.com/watch?v=PXftnij0syM 과 BnB 공식 자료 https://ca.nexon.com/Info/Character 도 403이다. 영상 메타데이터·재생 프레임·캐릭터 옆모습을 내려받거나 확인하지 못했다. 외부 공개 저장소의 별도 sprite 검색도 결과가 없었으며 영상 대조를 대신하지 않는다.

환경 설정 초안의 명시적 허용 목록에 youtu.be, youtube.com, www.youtube.com, youtubei.googleapis.com, *.googlevideo.com, *.ytimg.com, ca.nexon.com, ssl.nexon.com, image.nexon.com 을 저장했다. 기존 package_managers 프리셋과 다른 설정은 보존했다. 초안 저장은 현재 환경에 적용하거나 게시하는 동작이 아니다. 사용자의 환경 설정 저장/적용 후 상태와 실제 접속을 다시 확인한다. 명시적인 접속 차단을 외부 중계 등으로 우회하지 않는다.

## 적용한 독립 수정

아이템은 생성 또는 사망 비행 착지 후 12초 유지한다(기존 6초의 두 배). 마지막 1.5초 페이드는 유지한다. 물풍선은 40px 타일의 고정 판정을 유지하고 표시 이미지만 4~6px 위아래로 움직인다. 그림자는 바닥에 남아 높이에 따라 좁아지고 옅어진다. 이는 사용자가 요구한 움직임 강화이며 영상에서 실측한 재현이라고 표시하지 않는다.

## 남은 외형 작업

접속이 허용되거나 사용자가 영상 파일을 첨부하면 실제 영상을 열어 방향별 장면과 시간대를 기록한다. 현재 제작된 옆·뒤 실루엣과 원작의 얼굴/헬멧 위치·앞/뒤 발 교차·바닥 기준점·동작 속도를 비교해 필요한 방향 그림을 교체한다. 13종 방향 걷기의 구현과 1:1 원작 외형 검증은 구분한다.

## 독립 수정 검증

타입 검사·제품 빌드·규칙/소켓 129개·전체 Chromium E2E 34개가 통과했다. 아이템 12초 유지, 각 착지 기준의 만료, 만료 후 픽업 금지를 검증했다. 물풍선의 실제 표시 좌표에서 3px가 넘는 상하 움직임과 바닥에 고정된 그림자·그림자 너비 변화, 게임 상태 불변을 확인했다. 지정 영상을 열어 보거나 원본 외형 일치를 확인했다는 의미는 아니다. Windows ZIP 생성·CRC·SHA-256을 확인했다.
