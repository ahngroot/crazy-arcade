# crazy myangcade · 크레이지 먕케이드

**[⬇ Windows 게임 ZIP 다운로드 (약 54MB)](https://raw.githubusercontent.com/ahngroot/crazy-arcade/main/crazy-myangcade-windows-x64.zip)**

최신 변경: 바닥 아이템은 22.5초 유지하며 마지막 3초에 옅어져 사라집니다(사망 드롭은 착지부터 계산). 벽이나 장애물에 막혀도 방향키를 누르는 동안 그 방향을 보며 제자리에서 걷고, 키를 떼면 멈춥니다. 겹친 방향키의 우선순위와 타일 중심 이동은 유지합니다.

각자의 PC에서 한 캐릭터를 조작하는 **온라인 1:1 꼬물이 대전**입니다. **1인 무제한 연습 모드**도 제공합니다. 한 PC에서 두 캐릭터를 함께 조작하는 기능은 제공하지 않습니다. 직접 만든 그림과 합성 음악을 사용합니다.

시작 전에 메뉴의 **캐릭터 선택**에서 13종 중 하나를 고르세요. 모든 캐릭터의 능력치는 동일합니다. 선택 후 1인 연습 또는 온라인 방 만들기·참가로 시작합니다. 연습 재시작과 온라인 재대결·재접속에서도 선택한 외형을 유지합니다. 선택은 이 브라우저에 저장됩니다.

## 조작

| 동작             | 키                      |
| ---------------- | ----------------------- |
| 내 캐릭터 이동   | 방향키 ↑ ↓ ← →          |
| 물풍선 설치      | Space                   |
| 다음 아이템 사용 | Ctrl (왼쪽·오른쪽 모두) |

팀과 관계없이 같은 조작을 사용합니다. WASD와 Enter는 게임 조작에 사용하지 않습니다. 바늘·보호막·파워는 **합계 최대 2개**, **획득 순서대로** Ctrl 한 번당 하나씩 사용합니다. 양쪽 Ctrl을 함께 누르거나 계속 누르고 있어도 중복 소비하지 않습니다. 능력치 강화는 획득 즉시 적용됩니다.

## 혼자 연습하기

메뉴에서 **1인 연습 모드**를 누르면 상대나 방 참가 없이 **3 → 2 → 1 → Game Start!** 후 시작합니다. 캐릭터는 한 명만 생성되며 시간제한 없이 이동·물풍선·상자 파괴·아이템·갇힘과 재생성을 연습할 수 있습니다. 조작은 방향키·Space·Ctrl입니다. 아이템 없이 시작하며 **처음부터 다시**로 맵·능력치·아이템을 초기화하고 카운트다운부터 다시 시작합니다. 온라인 연결이 끊겨도 연습은 사용할 수 있습니다.

맵은 **해적선 문양·해적선 돛대·블록 마을·보석 광산·컨테이너 공장·이끼 숲·고대 유적** 7종입니다. 연습과 온라인 모두 시작·초기화·재대결마다 직전과 다른 맵을 추첨합니다. 캐릭터도 이동할 수 있는 빈 타일에서 서로 겹치지 않게 무작위로 시작합니다. 사망과 재접속은 같은 맵을 유지합니다. 사진 기반 재현이며 픽셀 단위 동일본은 아닙니다. 맵 추가 방법은 [맵 안내](docs/maps.md)를 참고하세요.

## Windows EXE로 플레이

Windows 10/11 **64비트**용입니다. 어느 PC에도 Node.js·npm·Git을 설치할 필요가 없습니다. 혼자 하려면 EXE 실행 후 **1인 연습 모드**를 선택하세요. 온라인 대전은 아래 순서를 따릅니다.

1. **호스트 한 명**이 위 ZIP을 압축 해제하고 `crazy-myangcade.exe`를 더블클릭합니다.
2. 열린 브라우저에서 **온라인 대전 → 닉네임 → 방 만들기**를 선택합니다.
3. **초대 링크 복사**로 같은 공유기/LAN에 연결된 상대에게 링크를 보냅니다. 화면의 **상대 PC에서 열 주소**와 방 코드를 보내도 됩니다.
4. 상대는 받은 주소를 브라우저에 열고 닉네임을 입력해 **방 참가하기**를 누릅니다. 상대는 EXE를 따로 실행하지 않아도 됩니다.
5. 둘 다 **READY**를 누르면 경기장 중앙에 **3 → 2 → 1 → Game Start!**가 표시됩니다. 카운트다운이 끝나면 조작과 경기 시간이 시작됩니다. 종료 후 둘 다 **재대결 준비**를 누르면 새 경기가 시작됩니다.

호스트의 서버 창은 플레이하는 동안 켜 두세요. 종료는 창 닫기 또는 Ctrl+C입니다. 브라우저가 자동으로 열리지 않으면 창의 `GAME_URL`을 직접 여세요. 상대에게 보낼 주소는 `FRIEND_URL`입니다. `localhost`나 `127.0.0.1`은 각자의 PC를 뜻하므로 초대 주소로 사용하지 마세요. 각자 EXE를 켜면 별개의 서버가 생깁니다.

기본 포트는 3001이며 사용 중이면 빈 포트를 자동 선택합니다. 호스트의 Windows 방화벽에서 사용하는 사설 네트워크의 연결을 허용해야 합니다. 네트워크 어댑터가 여러 개면 상대와 연결된 주소를 선택하세요.

**서로 다른 집에서 접속하려면 두 PC가 접속할 공통 게임 서버 주소가 필요합니다. 현재 인터넷 공개 서버는 배포하지 않았습니다.** 같은 네트워크에서는 위 EXE로 플레이할 수 있습니다. [Windows 사용·제작 안내](docs/windows.md), [온라인 접속 안내](docs/online.md)를 참고하세요.

저장소 루트의 ZIP과 `.zip.sha256`을 직접 배포합니다. Code → Download ZIP은 전체 소스 다운로드입니다. 코드 서명이 없는 테스트 빌드라 Windows에서 미확인 앱 안내가 표시될 수 있습니다.

사망한 위치에서 아이템이 포물선으로 날아가 바닥에 착지합니다. 캐릭터는 타일을 채우도록 확대했고 바닥 아이템은 이전보다 1.5배 커졌습니다. 이동은 부드럽게 이어지면서 타일 중심에서 멈추거나 방향을 바꿉니다. 경기 화면을 확대하고 화면 크기에 맞춰 상태 패널을 배치합니다. [화면·조작 안내](docs/play-feel.md)를 참고하세요.

## 게임 규칙

기본 180초, 짧은 경기는 30초입니다. 초록 꼬물이를 물줄기로 잡으면 점수가 오르고 상대 소속 몬스터가 늘어납니다. 보라 까칠이는 닿으면 탈락합니다. 연속 처치는 콤보, 8연속 처치는 황금 몬스터 보상으로 이어집니다. 종료 시 점수가 높은 팀이 승리합니다.

- 물풍선은 2.5초 뒤 십자로 터집니다. 상자는 물줄기를 막고 파괴되며 다른 물풍선은 연쇄폭발합니다.
- 시작 사용 아이템은 없습니다. 보호막은 4초간 보호하고, 파워는 6초간 능력치를 늘립니다. 바늘이 맨 앞이면 갇혔을 때 사용할 수 있습니다.
- 바늘·쉴드는 연습과 온라인 모두 상자를 부수어 획득할 수 있습니다. 즉시 발동하지 않고 사용 아이템 칸에 저장됩니다. 첨부 이미지를 참고한 파란 머리 바늘·은색 쉴드 아이콘을 바닥과 보관 칸에 공통 적용했습니다.
- 액체·롤러스케이트·울트라 물풍선은 획득 즉시 적용되는 패시브입니다. 물줄기 +1·속도 증가·최대 물줄기 효과이며, 시간제한·보관 칸·Ctrl 사용이 없습니다. 장갑·신발·고스트는 테스트 동안 등장하지 않습니다.
- 울트라의 상자당 출현 확률은 기존의 절반인 3.75%입니다. 전체 아이템 출현 확률 45%는 유지합니다. 파란 얼굴 물풍선은 개수 +1 아이템이며, Space 설치 풍선은 일반·울트라 모두 별이 반짝이는 보라색 구체입니다. 상하 흔들림과 폭발 직전 빨라지는 맥동을 표시합니다.
- 물풍선에 갇히면 5초 동안 기본속도의 40%로 움직입니다. 기포와 몸부림이 점차 빨라지며, 시간이 끝나면 질식·파열·쓰러짐·사라짐 후 재생성됩니다.
- 죽으면 보관 중인 사용 아이템과 현재 물풍선 개수·속도 강화분을 주변 바닥에 무작위로 떨어뜨립니다. 물줄기와 울트라는 떨어뜨리지 않습니다. 물줄기·개수·속도·보관함·버프를 초기화해 기본 스펙으로 재생성합니다. 이미 사용했거나 교체로 버린 아이템은 다시 나오지 않습니다.
- **1번·2번 아이템 칸**에는 최근 획득한 사용 아이템 2개를 보관합니다. `[1번 A, 2번 B]`에서 새 아이템 C를 먹으면 A를 버리고 `[1번 B, 2번 C]`가 됩니다. Ctrl은 1번부터 사용합니다. 물풍선 개수·거리·속도·울트라 강화는 보관 칸과 교체에 영향을 주지 않습니다.
- 탈락해도 안전한 위치에서 재생성됩니다. 마지막 30초는 몬스터 생성이 빨라지고 마지막 15초는 경고를 표시합니다.
- 기본 소리는 꺼져 있습니다. **소리 켜기**를 누르면 직접 합성한 배경음악과 효과음이 재생됩니다.

점수·아이템·물풍선·몬스터·승패는 서버가 판정합니다. 연결이 끊기면 30초 동안 자리를 예약하고 경기를 잠시 멈춥니다. 같은 탭을 새로고침하면 자리를 복구합니다. 명시적 나가기나 유예 초과는 기권입니다. 방과 점수는 서버 종료 시 사라집니다.

## 소스로 개발·실행

개발 PC에는 Node.js **24.x**와 Git이 필요합니다.

```sh
git clone https://github.com/ahngroot/crazy-arcade.git
cd crazy-arcade
npm ci
npm run dev
```

| 실행 방법                      | 호스트 PC               | 같은 네트워크의 상대 PC |
| ------------------------------ | ----------------------- | ----------------------- |
| `npm run dev`                  | `http://localhost:5173` | `http://호스트-IP:5173` |
| `npm run build` 후 `npm start` | `http://localhost:3001` | `http://호스트-IP:3001` |

Vite는 `/health`, `/connection-info`, `/socket.io`를 3001 포트의 서버로 프록시합니다. 개발 서버와 빌드 서버를 같은 포트에서 동시에 실행하지 마세요. 빌드 서버의 포트는 `PORT` 환경 변수로 변경합니다. `.env`를 자동으로 읽지는 않습니다. DB·API 키·회원 계정은 필요하지 않습니다.

클라우드 내부의 localhost는 사용자 PC에서 여는 공개 주소가 아닙니다. 공개 배포는 보류 중이며 `render.yaml`과 [배포 안내](docs/deploy.md)는 준비되어 있습니다.

## 검증 및 빌드

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run package:windows
npm run test:portable -- release/crazy-myangcade.exe
```

Linux에서는 `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`를 사용할 수 있습니다. `npm run package:host`와 `npm run test:portable -- release/crazy-myangcade-linux`로 동일한 포터블 실행 경로를 검증합니다.

이번 유지 시간 조정 후 타입 검사·제품 빌드·Vitest **131개**와 아이템 비행/착지·페이드 브라우저 검사 **1개**를 통과했습니다. 이전 전체 Chromium 검사 **38개**에서는 벽 앞 제자리 걷기·키 해제 정지, 13종 방향별 걷기와 기존 연습·온라인 재접속/재대결을 확인했습니다. 자세한 범위는 [캐릭터 그림 안내](docs/character-motion.md), [화면·조작 안내](docs/play-feel.md)와 [Windows 안내](docs/windows.md)를 참고하세요.

실제 서로 다른 집의 PC 두 대, Windows Chrome/Edge 수동 조작, 원작 조작감·수치 일치 여부는 추가 확인이 필요합니다. Phaser 청크 크기 경고는 알려진 상태이며 실행 오류는 아닙니다.

## 구성과 개발 이어가기

| 경로                                      | 역할                                                   |
| ----------------------------------------- | ------------------------------------------------------ |
| `apps/client/src/main.ts`, `game.ts`      | 1인 연습·온라인 메뉴·HUD·한 캐릭터 입력·렌더링         |
| `apps/client/src/online.ts`, `netcode.ts` | 방·재접속 UI, 내 이동 예측과 보간                      |
| `apps/server`                             | 방·세션 관리, 서버의 경기 판정, Socket.IO, 포터블 실행 |
| `packages/shared`                         | 공통 상태·규칙·맵·엔진                                 |
| `tests`, `scripts`                        | 브라우저 검증, 성능 측정, 배포·실행 검증               |

각 작업이 끝나면 검증 후 커밋·푸시합니다. 다른 PC에서는 GitHub `main`을 clone하고 `npm ci`를 실행하세요. 기존 체크아웃은 미반영 변경을 확인한 뒤 `git pull --ff-only origin main`으로 갱신합니다. 실행 중인 서버와 방·세션은 Git에 저장되지 않습니다.

현재 제품은 **1인 연습 + 온라인 1:1 대전**을 제공합니다. 이전 기록의 로컬 2인 플레이는 제거했으며, 연습 모드는 한 캐릭터만 사용하는 형태로 복구했습니다. 공개 배포는 별도 단계입니다.
