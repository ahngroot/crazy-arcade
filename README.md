# Bubble Critter Duel · 버블 크리터

`ahngroot/crazy-arcade`에서 개발하는 독자 리소스 기반 2인 아케이드 웹게임입니다. 현재 **3단계: 로컬 꼬물이 경쟁 모드**까지 구현되어 있습니다. 한 PC에서 두 사람이 몬스터를 처치하고, 상대 진영에 몬스터를 보내며 점수를 겨룹니다. 별도의 무제한 물풍선 연습도 제공됩니다. 서로 다른 PC의 인터넷 대전은 4단계에서 구현합니다.

## 실행

Node.js 24 LTS와 npm이 필요합니다. 저장소 루트에서:

```sh
npm ci
npm run dev
```

개발 클라이언트: `http://localhost:5173`, 서버 건강 검사: `http://localhost:3001/health`.
이 주소는 서버가 실행 중인 PC/클라우드 환경 안에서만 유효합니다. 클라우드의 localhost는 사용자 PC의 localhost와 다릅니다. 현재 외부 접속 주소는 배포하지 않았습니다.

Vite가 `/health`와 `/socket.io`를 서버로 프록시합니다. 개발 시 기본 포트 5173/3001을 사용하세요. 비밀키나 DB는 필요하지 않습니다.

## 검증 및 빌드

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

이미 Chromium이 설치된 Linux 환경에서는 `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`로 사용할 수 있습니다. E2E는 개발 서버를 자동 시작하고 종료하며 실제 캔버스 렌더링, 서버 연결, 화면 전환, 좁은 화면 레이아웃과 두 사람의 키 입력·물풍선·갇힘·재생성·재시작을 검사합니다. 스크린샷은 `test-results/`에 생성됩니다. GPU 렌더링 테스트는 한 worker로 실행합니다.

빌드 후 `npm start`로 서버와 정적 클라이언트를 한 포트(기본 3001)에서 실행할 수 있습니다. 포트는 `PORT` 환경 변수로 설정합니다. `.env` 자동 로딩은 하지 않습니다. Socket.IO는 동일 출처 요청만 허용합니다. 실제 공개 서비스용 보안 검증은 7단계 범위입니다.

## 꼬물이 대전

메뉴에서 **꼬물이 대전**을 누르세요. 기본 180초이며, 빠른 테스트는 **경기 시간 → 짧게 30초**를 선택하세요. 초록 꼬물이는 닿아도 안전하지만 보라 까칠이는 닿으면 탈락합니다. 물줄기로 처치하면 점수가 오르고 상대 진영에 일반 몬스터가 늘어납니다. 3초 안의 연속 처치는 콤보, 8연속마다 자기 진영에 황금 몬스터가 등장합니다. 공간이 없으면 생성 대기합니다.

| 플레이어 | 이동   | 물풍선 | 바늘 | 보호막 | 파워 |
| -------- | ------ | ------ | ---- | ------ | ---- |
| P1 빨강  | WASD   | Space  | Q    | E      | R    |
| P2 초록  | 방향키 | Enter  | J    | K      | L    |

- 바늘은 갇힘을 풀고, 보호막은 4초간 피격을 막으며, 파워는 6초간 이동속도·물줄기·물풍선 개수를 늘립니다. 각 특수 아이템은 1개씩 시작하며 까칠이/황금 보상으로 추가 획득합니다. 소지 개수와 남은 효과 시간은 우측에 표시됩니다.
- 죽어도 안전한 위치에서 재생성합니다. 시간이 끝나면 점수로 승패/무승부를 결정하며, **재대결**로 새 라운드를 시작할 수 있습니다. 마지막 30초는 생성이 빨라지고 마지막 15초는 별도 경고를 표시합니다.
- 시작할 때 물풍선을 두고 아래로 충분히 피하거나 보호막을 먼저 사용해 통로를 확보하세요. 몬스터·점수·시간은 같은 화면에서 함께 확인합니다.

점수, ‘4마리 기준’의 임시 해석, 몬스터 AI와 상한/대기열, 아이템·라운드 설정과 검증 범위는 [docs/competition.md](docs/competition.md)를 참고하세요. 원작 규칙이나 수치를 그대로 검증한 게임은 아니며 현재 해석을 문서에 구분했습니다.

## 연습 모드 플레이

메뉴에서 **연습 모드**를 누르세요. 키보드 조작은 PC를 기준으로 합니다.

| 플레이어 | 이동   | 물풍선 |
| -------- | ------ | ------ |
| P1 빨강  | WASD   | Space  |
| P2 초록  | 방향키 | Enter  |

- 물풍선은 한 번 누를 때 하나 설치됩니다. 기본 1개, 2.5초 뒤 십자 폭발, 물줄기는 0.5초 지속됩니다.
- 벽은 통과할 수 없으며 상자는 물줄기를 막고 파괴됩니다. 다른 물풍선은 즉시 연쇄폭발합니다.
- 설치한 칸을 빠져나올 수 있지만 완전히 떠나면 다시 들어갈 수 없습니다.
- 상자를 부수면 확률적으로 아이템이 나옵니다. 파란 구슬은 물풍선 개수, 십자는 거리, 초록 화살표는 이동속도를 늘립니다. 물줄기가 사라진 뒤 아이템 칸으로 이동하면 획득합니다. 능력치는 우측에 표시됩니다.
- 물줄기에 닿으면 1.5초간 갇힌 뒤 사라지고 0.8초 후 안전한 칸에 재생성됩니다. 이후 1.5초 무적이며 획득 능력치는 유지됩니다.
- 창을 벗어나면 입력을 초기화합니다. 숨겨진 탭은 시뮬레이션을 멈추며, 돌아왔을 때 장시간 입력을 몰아서 처리하지 않습니다.
- **처음부터 다시**는 맵·아이템·능력치·재생성 횟수를 초기화합니다. 메뉴로 나가면 해당 연습은 종료됩니다.

빠른 확인: 시작 위치에 물풍선을 두고 아래로 두 칸 이상 피하면 안전하게 상자를 부술 수 있습니다. 그대로 서 있으면 갇힘과 재생성을 확인할 수 있습니다. 기본 진영이 분리되어 있어 서로 직접 공격하지 않습니다. 연습에는 시간제한·몬스터·점수·승패가 없습니다.

온라인 대전 버튼은 연결 상태와 미구현 기능을 안내합니다. 온라인 서버가 끊겨도 로컬 경기와 연습은 동작합니다. 다음은 **4단계 서버 권위형 온라인 2인 대전**이며, Docker/Render 공개 배포는 7단계입니다.

## 현재 검증 결과

Node.js 24.19.0 환경에서 기존 물풍선 엔진과 새 몬스터 경쟁 규칙을 검증합니다. 테스트는 이동·충돌·연쇄·피격·재생성·아이템 외에도 처치 점수, 상대 전달, 콤보/황금, 추격 AI, 특수 아이템, 상한/대기열, 승패/무승부, 종료 후 상태 불변성과 시드 재현을 검사합니다. 180초 전체 경기는 로직 테스트로, 30초 경기의 시작→실제 키보드 입력→종료→재대결은 브라우저에서 확인합니다. 실제 Windows Chrome/Edge, 키보드별 동시 입력 제한과 외부 인터넷 접속은 아직 별도 검증이 필요합니다.

3단계 최종 검증: 타입 검사·빌드, Vitest **38개**, Chromium Playwright **8개** 통과. 브라우저 캡처에서 양쪽 몬스터 처치 점수 증가와 동점 결과 표시도 확인했습니다.

빌드에는 Phaser 엔진이 포함된 지연 로딩 청크(약 1.37MB, gzip 약 358KB)에 대한 크기 경고가 남습니다. 실행 실패는 아니며 추후 로딩 성능 최적화 대상으로 관리합니다.

## 다른 PC에서 이어서 개발

각 단계가 끝나면 테스트 후 커밋·푸시하는 방식으로 진행합니다. 다른 PC에서는 GitHub의 `main`을 clone/pull하고 Node.js 24로 `npm ci`, `npm run dev`를 실행하세요. 실행 중인 서버 프로세스는 Git에 저장되지 않으며, 푸시와 인터넷 배포는 별개입니다.
